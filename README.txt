JP Captions - Japanese audio -> English live captions (Android)

BUILD THE APK (no coding):
 A) GitHub (easiest, ~5 min)
   1. Create a free GitHub account, make a new repository.
   2. Upload ALL files from this folder (keep the .github folder!).
   3. Open the "Actions" tab -> "Build APK" -> wait for the green check.
   4. Open the run -> Artifacts -> download JP-Captions-APK -> unzip -> app-debug.apk
 B) Android Studio: File > Open this folder > Build > Build APK(s).

INSTALL: copy app-debug.apk to your phone, open it, allow "install unknown apps".

USE: open app (internet needed once to download the ~30 MB translation model),
allow microphone, tap START, play Japanese audio near the phone mic.
